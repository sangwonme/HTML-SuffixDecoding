## 5. Secrets and personal information (grep, excluding `.venv`, `.cache`, `models`, `data`)
- API keys and tokens: **none found**. Patterns checked: `hf_…`, `sk-…`, `ghp_…`, `AKIA…`, `api_key=`, `password=`, private key headers, `HF_TOKEN`, `OPENAI_API_KEY`.
- No `.env` file. Model downloads did not need a token (gated=False, NOTES.md §7).
- Local user paths (`C:\Users\…`) appear only in `paper/*.log` and `runs/retrieval/run.log`; both are excluded. Scripts use `ROOT`-relative paths.
  - One exception: the docstring of `scripts/bench_gemma.py` mentions `C:\Works\KSEF26\.gpu_busy`, a project path with no user name.
- E-mail addresses appear in model outputs and exemplar HTML under `runs/` (and in `data/processed`), for example `appcrawler*@gmail.com` and `student@school.edu`. They are RICO screen text (crawler accounts and placeholder text), i.e. part of the public CC-BY-4.0 data, not personal data from this project. Kept; noted here for main.

## 6. Licenses
- **Screen2Words / RICO-SCA**: HF `rootsautomation/RICO-Screen2Words`, whose card metadata says `license: cc-by-4.0` (checked in `data/raw/RICO-Screen2Words/README.md`).
  - Derived data (jsonl, review images) may be redistributed with attribution: Screen2Words (Wang et al., UIST 2021) and RICO (Deka et al., UIST 2017). README.md carries the attribution.
- **RICO original**: NOTES.md §2 records that mirrors label it CC-BY-4.0 but the official license was not confirmed. This stays an open item.
- **Gemma 4**: Apache-2.0 per the model card metadata (`models/gemma-4-E2B-it-qat-q4_0-unquantized/README.md`, Gemma 4 license link). Weights are not redistributed (excluded), and the "Gemma" name is a trademark.
- **Project code**: no license file exists. Main or the user needs to choose one before publishing.
